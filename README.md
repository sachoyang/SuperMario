# 🍄 유니티 2D 슈퍼마리오 브라더스 (Super Mario Bros. Unity Clone)

<img width="256" height="240" alt="title_screen" src="https://github.com/user-attachments/assets/be5786f4-0c99-4f98-8a97-29e72ba37d65" />

원작 패미컴(NES) '슈퍼마리오 브라더스(1985)'의 감성과 디테일, 그리고 물리법칙을 Unity 엔진을 사용하여 완벽하게 재현한 2D 플랫포머 게임입니다.

## 🌟 주요 기능 및 특징 (Key Features)

### 1. 원작 물리엔진 및 조작감 완벽 구현
* **가속도 및 관성:** 걷기와 달리기(Dash)의 가속도가 분리되어 있으며, 달리는 속도에 비례해 점프 비거리와 체공 시간이 달라지는 원작의 대시 점프 로직 적용.
* **디테일한 오브젝트 물리:** 마리오가 점프 중 아이템을 먹을 때 모멘텀이 끊기지 않도록 레이어 충돌 무시 및 레이더 판정 적용. 블록을 밑에서 칠 때 위에 있는 아이템(버섯, 별)이 튀어 오르며 걷는 방향을 반전하는 기믹 구현.

### 2. 레트로 해상도 및 디스플레이 대응
* **256x240 강제 렌더링:** 요즘 모니터 비율에서도 원작 NES 화면 비율이 절대 깨지지 않도록 위아래/좌우 블랙바(레터박스)를 자동 생성하는 해상도 고정 스크립트 적용.
* 창 모드 및 `Alt + Enter`(또는 F11)를 통한 전체화면 실시간 전환 지원.

### 3. 마리오 상태 변환 및 전투 시스템
* **상태 변화 (Small ↔ Super ↔ Fire):** 버섯과 꽃을 획득함에 따라 몸집이 커지고, 애니메이터를 분리해 상/하체 독립 애니메이션(파이어볼 투척 시) 구현.
* **파이어볼 시스템:** 카메라 화면 밖으로 벗어나거나 바닥의 구덩이로 떨어지면 즉시 디스폰되어 씬 당 2개 제한 규칙을 원작과 동일하게 적용.

### 4. 원작 디테일 및 맵 기믹
* **워프 파이프 연출:** 방향(아래, 위, 옆)과 진입/탈출 연출 유무를 인스펙터에서 자유롭게 제어 가능한 다목적 WarpPipe 시스템.
* **깃발(Flagpole) 클리어 로직:** 깃대의 잡은 높이에 따른 점수(1000~2000) 차등 지급, 꼭대기를 정확히 잡았을 때의 숨겨진 **1UP** 판정 구현.
* **긴박한 타임아웃 연출:** 남은 시간이 100초 이하로 떨어지는 순간, 진행 중인 BGM이 즉시 정지하고 경고음 재생 후 빠른 템포의 BGM(Fast Theme)으로 전환되는 디테일 적용.

### 5. 최적화된 데이터 및 사운드 관리 체계
* **싱글톤 매니저:** `GameManager`와 `SoundManager`를 통해 씬(Scene)이 전환되어도 점수, 코인, 목숨, 시간 등의 데이터와 오디오 소스가 끊기지 않고 유지되도록 설계.
* **데이터 영구 저장:** `PlayerPrefs`를 활용하여 디바이스에 최고 점수(High Score)를 저장하고 로드.

## 🎮 조작 방법 (Controls)

| Action | Key |
| :--- | :--- |
| **이동 (Move)** | `←` `→` 방향키 |
| **파이프 진입/앉기 (Crouch)** | `↓` 방향키 |
| **점프 (Jump)** | `Space` 또는 `Up` 방향키 |
| **달리기 / 파이어볼 (Run / Fire)** | `Z` 또는 `Left Ctrl` (누른 상태 유지) |
| **전체화면 전환 (Fullscreen)** | `Alt + Enter` 또는 `F11` |
| *(Dev Cheat)* 시간 110초 변경 | `I` |

## 🏗️ 핵심 시스템 구조 (Architecture)

* **`GameManager.cs`**
  * 싱글톤 패턴 적용. 점수, 코인, 목숨, 시간 관리.
  * 스테이지 전환, 타임오버, 게임오버 상태 제어 및 `PlayerPrefs`를 이용한 최고 점수 세이브/로드.
* **`SoundManager.cs`**
  * BGM 및 2D SFX 글로벌 관리. 코루틴을 활용한 100초 경고음 및 BGM 템포 체인지 제어.
* **`MarioCtrl.cs`**
  * 플레이어의 입력을 받아 물리 이동, 점프 관성, 애니메이션 상태(Small/Super/Fire) 변경, 데미지 처리 및 워프 코루틴 실행.
* **`InteractableBlock.cs`**
  * 물음표/벽돌 블록. 피격 시 코인/아이템 생성, 블록 깨짐 파편(`BrickDebris`) 생성 및 위에 있는 적/아이템 감지(`OverlapBoxAll`).
* **`CameraResolution.cs`**
  * 기기의 해상도를 스캔하여 Viewport Rect를 조절, 256x240 픽셀 퍼펙트 화면비 강제 유지.
